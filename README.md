# BrokenVK Support Bot

Telegram-бот поддержки: читает почту по IMAP, присылает заявки в чат модераторов,
отвечает клиентам через SMTP. Есть чёрный список адресов.

## Установка

pip install -r requirements.txt

## Настройка

Открой `main.py` и заполни блок «НАСТРОЙКИ ПРОЕКТА»:
токен от @BotFather, ID чата модераторов, почту и пароль приложения.

## Запуск

python3 main.py

## Команды модераторов

/ignore адрес причина — добавить в игнор

/unignore адрес — убрать из игнора

/ignorelist — показать список игнор почт
